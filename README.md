# **Weather App ⛅**  
*A real-time weather app built with Jetpack Compose and MVVM architecture.*

[![Google Play Store](https://img.shields.io/badge/Download-Google%20Play-blue.svg)](https://play.google.com/store/apps/details?id=com.yiying.shoppingapp)  

---

## **📌 Features**  
- **Live Weather Updates** – Get real-time weather conditions  
- **MVVM Architecture** – Clean separation of concerns and scalability  
- **API Integration** – Uses **Retrofit** and **Coroutines** for network calls  
- **Offline Support** – Implements **Room Database** for data caching  
- **Background Data Updates** – Uses **WorkManager** for periodic refreshes  
- **Dynamic UI with Jetpack Compose** – Modern UI for seamless interaction  
- **Location-Based Forecasts** – Fetches weather data based on device location  
- **Testing** – Includes **unit, integration, and UI tests** with JUnit & Mockito

## **🛠️ Tech Stack**
### **Frameworks & Libraries**
- **Jetpack Compose** – Declarative UI framework  
- **MVVM Architecture** – Clean separation of UI & logic  
- **Hilt (Dagger)** – Dependency Injection  
- **Room Database** – Local storage for offline access  
- **Retrofit & Coroutines** – API calls & asynchronous data fetching  
- **WorkManager** – Background data updates every 5 minutes  
- **Location Services** – Fetches real-time weather data  
- **Coil** – Image loading for weather icons  
- **JUnit, Mockito, Espresso** – Unit & UI Testing
